# Tienda de Bolsos - Catalogo Web

Aplicacion web de catalogo de bolsos con busqueda
y filtros por categoria y color.

## Archivos

- index.html   -> estructura HTML con layout sidebar + grilla
- estilos.css  -> diseno visual con panel lateral de filtros
- app.js       -> logica de filtrado y renderizado dinamico

## Uso

Abrir index.html directamente en el navegador.
No necesita servidor ni instalacion.

## Funcionalidades

- Panel lateral con filtros organizados
- Busqueda por nombre en tiempo real
- Filtro por categoria y por color
- Contador dinamico de resultados encontrados
- Aviso cuando no hay productos que coincidan
- Boton para resetear todos los filtros
- Responsivo para movil y escritorio
